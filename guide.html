How to make FINTECH Circle content

This playbook is for the FINTECH Circle team. It covers how to make a batch of 10 LinkedIn posts for Susanne with Claude Code and the content engine, how to review it here, and how to post it. Nothing is ever posted or scheduled automatically: a person posts every approved post.

The weekly rhythm

  1. Monday: ideasClaude proposes 10 ideas from the knowledge base and recent webinars. The owner picks or edits them.
  2. Tuesday: buildClaude writes, designs and renders the batch: 6 carousels and 4 single images. Every check must pass.
  3. Wednesday: reviewThe team and the owner review each post on the review page, tick Team and Owner, and leave feedback.
  4. Thursday: fixClaude applies the feedback and republishes. A post is ready when both boxes are ticked.
  5. Following week: postA team member posts each approved post at 08:30 UK and adds the first comment with the link.

One-time setup (per laptop)

You need access to the private repo growthclub-ai/fintech-circle-content, Claude Code, Python 3.10 or newer, Node 18 or newer and Git. Then run this once in a terminal:

git clone https://github.com/growthclub-ai/fintech-circle-content.git
cd fintech-circle-content
python -m pip install -r requirements.txt
python -m playwright install chromium

Kie.ai images (only needed for new scenes of Susanne): put the key in a file outside the repo, never in the repo itself.

# Windows PowerShell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.config\fintech-circle\keys"
Set-Content -Path "$env:USERPROFILE\.config\fintech-circle\keys\kie.env" -Value "KIE_API_KEY=paste_the_key_here"
Never paste a key into a chat, a post, a file inside the repo or a commit.

Make a batch, step by step

  1. Open the repo in Claude CodeOpen the fintech-circle-content folder in VS Code with the Claude Code extension, or run claude in that folder.
  2. Paste the batch promptUse the prompt below. Claude reads RULES.md, the voice, the facts and the knowledge base first.
  3. Pick the ideasClaude lists 10 ideas, each with a hook, a format and the facts it uses. Reply with your picks and changes.
  4. Add anything new as a fact firstA new number, quote or story goes into content/corpus/facts.md with its source before it appears in a post. If Susanne shares a story, paste it in and say it is hers.
  5. Let Claude build, render and checkIt copies the last batch builder (for example kits/content/batches/b3_build.py to b4_build.py), writes the copy, renders every page and runs the gates and an independent critic.
  6. Publish the review pageClaude runs merge_batch.py all, publish.py and the deploy. The new batch appears in the sidebar of this site.

The commands Claude runs (for reference)

python kits\content\batches\b4_build.py
python kits\content\render.py outputs\content\batch-4\T1 outputs\content\batch-4\T2 ...
python kits\content\gates.py 4
python kits\content\merge_batch.py all
python kits\content\publish.py
node kits\content\deploy.mjs --github https://github.com/growthclub-ai/fintech-content-review.git

The batch prompt (copy into Claude Code)

Make batch N of FINTECH Circle LinkedIn content for Susanne Chishti: 10 posts, 6 carousels and 4 single images.

Before writing, read RULES.md, content/corpus/voice.md (including the Hooks section), content/corpus/facts.md,
content/corpus/knowledge-base/README.md and the last BUILD_STATE file in outputs/content/.

1. Propose 10 ideas first and wait for my picks. For each: the hook (first two lines), the format from the
   format gallery, the CTA (webinar or Board Programme) and the fact rows it uses.
2. After I pick: copy the last batch builder to kits/content/batches/bN_build.py and build the posts.
   Covers and closing slides use the Kie.ai scenes in content/brand/people/susanne/avatars/.
3. Every claim must resolve to a facts.md row. No invented numbers, results or stories. No em or en dashes.
   UK spelling, no emoji, max 3 hashtags, no closing question, the link only in the first comment.
   Every list item in a caption starts with "• " (or "1." for steps).
4. Hooks: a first-person credential or hard number, a short flip line, then a promise with an arrow.
5. Render every post, run gates.py N until 0 failures, then run an independent critic pass and fix what it finds.
6. Add batch N to content/queue/batches.json, run merge_batch.py all and publish.py, deploy to the review site,
   write outputs/content/batch-N/BUILD_STATE_BN.md, commit on a branch, open a PR and merge it to main.
Do not post or schedule anything.

To apply review feedback later:

Read the feedback on batch N in the review sheet (or I paste it below), fix each post, re-render, re-run the gates
and the critic, republish the review site and merge to main. Tell me what changed per post.

Writing hooks that earn "see more"

LinkedIn shows about two lines before "...more". Those lines decide everything.

PatternExample from our posts
Credential, then a flip30 years in finance and technology taught me this about board seats: / Being a strong leader isn't enough. / Being visible is.
Hard numberVenture investors won't back a fintech growing at 10%. / They want one that could be a 10x.
What I learnedI spent years helping fintechs raise capital. / Here's what I learned: / Fintechs don't only run out of money. / They run out of adult supervision.
A list with a promise5 things to check before you accept any board seat. / Including the people you'll be sitting next to.
Myth brokenThe days of one AI expert on the board are over. / Every director is now expected to understand AI.

A stronger hook needs real material: Susanne's own stories, Board Programme results (placements, NED roles landed, cohort numbers) or a free resource to give away. Send them in and add them to facts.md first.

The rules every post passes

Always

  • Every number, name, date and quote from a facts.md row
  • Her quotes word for word, hedges kept ("might", "probably")
  • UK spelling, executive and warm in tone
  • Every list item in a caption starts with • (or 1. 2. 3. for steps)
  • The link only in the first comment, with UTM tags
  • Carousels of 8 to 12 pages, 1080 by 1350
  • The next webinar date confirmed before scheduling

Never

  • Em or en dashes anywhere
  • Invented results, anecdotes or statistics
  • The 260,000 community figure (blocked until confirmed)
  • The name of the bank she sits on
  • Emoji, more than 3 hashtags, a closing question
  • Posting or scheduling without the Owner tick

Images of Susanne

Susanne consented to AI scenes made with Kie.ai from her two reference photos. Eight scenes exist (stage, boardroom, screen, City walk, board papers, founder conversation, panel, atrium) in content/brand/people/susanne/avatars/. Reuse them first: they cost nothing. A new scene costs about 4 credits:

python kits\content\image.py credit
python kits\content\avatars.py create susanne <new-pose>

Add the new pose and its prompt to content/brand/people/susanne/person.json first. Scenes illustrate a lesson; a caption never says the scene really happened.

Review and approve on this site

  1. Open Review postsPick the batch in the sidebar. Each post shows as it will look in the LinkedIn app. Swipe carousels; tap "...more" to read the whole post.
  2. Write your name once, then feedbackFeedback is saved to the shared review sheet and appears for everyone. Wait for "✓ Saved".
  3. Tick Team or OwnerThe team ticks Team when the post is right. Only the owner ticks Owner. A post is approved when both are ticked.
  4. Use the filter"Needs review" shows what is left; "Approved" shows what is ready to post.

Posting an approved post

  1. DownloadUse "Download PDF" for a carousel (upload it as a document) or "Download PNG" for an image. These are full quality.
  2. Copy the postUse "Copy post copy" and paste it into LinkedIn on Susanne's profile. Check line breaks survived.
  3. Post at 08:30 UKOn the date shown on the card.
  4. Add the first comment straight away"Copy first comment" holds the link with its tracking tags.
  5. Tell the teamShare the live post link so the team can engage in the first hour.

When something fails

You seeDo this
A gate says a number has no facts.md rowAdd the fact with its source, or remove the number. Never relax the gate.
A banned dashRewrite with a full stop, comma, colon or "to".
Hook over 140 charactersShorten the first paragraph; move detail to line 3.
Sync badge says "Offline"Your feedback is kept in the browser and retried. Reload later; do not clear the browser.
Kie.ai says no creditsAsk the owner to top up; reuse the existing scenes meanwhile.
