Issues found and recommended changes
  • Capitals: runs 3 and 5 changed "What we'll cover", "Designed for" and "The FINTECH Circle Team" to all capitals. These are shown in red on the phones.
  • Barclays not personalised: both templates came back with only the greeting, yet each run still used about 14,500 tokens. The crawler probably fetched cookie, legal or navigation text, so the prompt correctly left the template unchanged.
  • The prompt was written for V6: its "must stay exactly" list quotes V6 wording, so those safeguards don't cover the Personalised Template.
  • Name used twice: the prompt says to use the name only in the greeting, but the Personalised Template's closing line also uses it ("We look forward to seeing you there, James.").
  • Slow: at about 28 seconds each, 1,000 invites take about 7.7 hours if Tantra runs them one at a time.
  1. Switch on a default provider in Tantra (Connectors, then LLM Providers).
  2. Move bulk sending to an OpenRouter API key with a monthly spend limit and a low-balance alert. Keep the Claude plan for writing and testing prompts.
  3. Cap the website excerpt, or check the "Use external crawler" setting. This saves the most money.
  4. Rerun these 8 domains on Haiku 5.5 and compare the results with this page.
  5. Prompt fixes (not yet saved in Tantra): require every unchanged line to be copied exactly, including capitals; make the "must stay" list neutral to the template; allow the name wherever the template already uses it.
